Paste a link — or a whole message. The tracking junk comes off, and the link still works. Nothing you paste leaves this page.

Loading the cleaning engine — about 6 MB, once, then it works offline.

    This page runs nudl's own cleaning engine — the same Python file the Windows app uses — right here in your browser, with Pyodide. There is no server to send your text to, and the page's security policy wouldn't let it anyway.

    It only strips parameters it knows are tracking, and leaves signed links and anything it isn't sure of alone. What it removes, and what it deliberately doesn't.

    On Android, install this page (browser menu → Install app) and it appears in the Share menu: share a link to nudl, copy it back clean. It's handled on the phone, never sent anywhere.

    Everywhere you copy links: winget install Coreho.nudl (Windows tray app: a hotkey that cleans whatever you copied, or automatic mode) · pipx install nudl (command line on Windows, macOS and Linux — nudl --clipboard is the hotkey for any OS) · GitHub
